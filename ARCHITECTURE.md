# OS Shell 2.0.1 — Production Hardening

OS Shell is a thin web-native operating environment: host applications, mediate permissions and capabilities, coordinate objectives and place — without owning domains or infrastructure.

Protocol: `channel: "os-shell"`, `version: "0.7"`. Package version: `2.0.1` (production hardening of the **2.0** feature set — not a 2.1 expansion). Developer contract: `1.3`. Distribution: `1.2`. Interoperability: `1.3`. Continuity (sessions): `1.4`. Object/Action: `1.5`. Search/Discovery: `1.6`. Objectives/Workflows: `1.7`. Preferences/Routing: `1.8`. Cross-app continuity: `1.9`. Personal Operating Context: `2.0`. Production release: `2.0.1`.

## Permanent architecture

```
HUMAN → OBJECTIVE → OS SHELL
  (Discover · Resolve · Route · Preference · Continuity · Operating Context)
→ PERSONAL OPERATING CONTEXT
→ OBJECT / ACTION / SESSION → INTENT → APPLICATION → EXECUTE → Six Primitives
```

## Personal Operating Context Plane

Answers: **“What is relevant to this person right now?”**

```
Shell coordinates.
Applications own the work.
Primitives provide infrastructure.
```

Operating Context is a Shell plane — not a seventh primitive, not a universal profile, not an AI agent.
